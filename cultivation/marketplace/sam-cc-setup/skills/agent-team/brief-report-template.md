# Worker brief and report template

Two skeletons for the brief-and-report protocol.
The lead writes `brief.md`; the worker writes `report.md` before it stops or when interrupted.
Both live under `.superpowers/sdd/<task>/`, and both carry the same seven HANDOFF fields, in the same order, one heading each.

## brief.md

### Goal
### Files touched
### Commands run (each with its exit code)
### Tried and failed
### Open assumptions
### Next single action
### Written at (git rev-parse HEAD)
