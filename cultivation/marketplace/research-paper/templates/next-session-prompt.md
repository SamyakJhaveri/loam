# Next session: <one-line goal>

Copy this file for each handoff, replace each guidance line with a few lines of your own, and keep the five headings.

## Goal and why

The one outcome the next session must reach, and why it matters now.

## Constraints

What must not change: decisions already made that the session must not reopen, files it must not touch, and limits on time, agents or cost.

## Done check per task

For each task, the command, file or observation that proves it is done, with the expected result.

## Session conduct

How to work: what to read first, when to stop and ask the author, how to report, and when to commit.

## Target model and effort

The model and effort level the session should run on, and why.
