## Reuse discipline

Recommendation: a reusable piece receives its upstream URL, pinned source revision/file, actual copied scope, license/notices, local adaptation rationale, dependencies and a runnable behavioral acceptance check. Preserve this provenance in the managed payload that reaches every seed. An implementation example can be valuable while its error handling, policy defaults or dependencies are unsuitable. No external runtime code has been copied into Loam during this design phase.

Risks: inaccessible originals remain explicit gaps. Selected reference sections are not full API audits. The original output field-guide PDF was used for URL extraction here; its full prose/visuals are not newly claimed read. The architecture-review PDF was separately read in full as recorded in grounding-record.md. Proposed native behavior and improvement quality need authorized implementation-time probes.
