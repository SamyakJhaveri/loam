## What is here

- `source-manifest.json`: original and resolved source paths, exact SHA-256 identities and inactive snapshot destinations.
- `sources/*.txt`: selected definition/reference text copied without changes. The text extension and non-executable modes prevent accidental native skill/configuration discovery. These are incomplete source-reference selections, not deployable bundles.
- `loam-inventory.json`: current local curated definitions, support dependencies, parked state and declared remote bundles.
- `baseline-adoption-map.json`: exact proposed shared-seed destinations and required adaptation for every local curated skill.
- `benchmark-inventory.json`: ParBench and DistBench asset definitions, native variants, aliases, review dispositions and source identities.
- `application-inventory.json`: job-search assets and the organizer's reference to the global experiment-loop skill.

The inventory authors' suggested optional plugin homes are research recommendations. The current user requirement and the adoption plan take precedence: reusable curated capabilities intended for every seed have a canonical shared seed home; project-specific adapters stay project-owned.
