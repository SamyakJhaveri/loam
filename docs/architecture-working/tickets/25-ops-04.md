## What to build

Verified current behavior: accepted D-OFFLINE and D-PERSONAL-GPU are recorded design policies; the proposed runtime does not yet enforce them. Let already started fixed GPU work continue within its admitted time/resources/access envelope while the Mac is disconnected. Native agents default to interruption. Native reasoning embedded in a GPU request makes it native work; autonomous continuation requires separate task authority.

Persist policy, execution budget, stop/checkpoint behavior, bounded stop grace and renewable control lease before launch. Each independent job host enforces connection gates and expiry even when the runner is down. Detected controller/runner loss or failed renewal closes submission, prepared/queued final dispatch and positive-approval gates immediately. Native interruption happens at the previously admitted lease deadline, not an invented earlier deadline; silent loss is bounded by expiry. Reconnect before expiry may reopen eligible gates only after current-authority handshake and pending barriers. Reconnect after recorded interruption is not implicit native restart. No renewal, suspend, clock change, reconnect or reboot extends the GPU maximum or resets consumed budget; uncertain enforcement blocks continuation. A checkpoint resume is a separately authorized linked attempt.

For this personal machine, start eligible work when capacity permits; otherwise show a cancellable queue with expiry, or requested fail-fast. Choose routine configurable defaults. Check external contention without killing another workload. Queue eligibility never authorizes offline starts. Do not add multi-user scheduling, priorities or a resource-policy questionnaire.
