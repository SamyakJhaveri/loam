## Acceptance
- Locked factory dependencies stay independent of research/root packages. Compile fixture sources into `dist/tests/`; recipients execute supplied JavaScript without compiling TypeScript. Build/install never launches a provider.
- Independently rebuild the frozen candidate in scratch and compare its complete compiled output file set, including stale extras and sourcemaps. Do not regenerate candidate output before comparison. Reject machine paths and timestamps that defeat reproducibility.
- Fixed verification registry rejects unknown/unbuilt groups, missing cases, and empty populations. Later full groups explicitly report unavailable.
- Release package fixture renders the exact candidate payload without personal caches and verifies byte-for-byte source/build delivery and absence of private state. This ticket proves package closure, not the S6 product matrix. Preserve the separate release/recipient boundary.
- Future commands, in order: `npm --prefix seed/.loam/factory ci`; `npm --prefix seed/.loam/factory run build`; `node --test seed/.loam/factory/dist/tests/installation/package.test.js`; `node --test bin/tests/factory-release-render.test.mjs`. Mutated source without updated dist, deleted/extra dist files, absent case/tool and a colliding project package must be rejected; exact matching package passes with explicit counts.

## Exclusions
No protected installation or store creation, native invocation, controller replacement, update matrix completion or validated runtime pin claim. Pin candidates for reproducible qualification; CORE-02 determines support.
