1. Recheck current source, existing recommendation and available requested skill. Check: `git status --short`, `git rev-parse HEAD`, source reads and skill filename/content search. Expected current main and documentation-only changes; report a missing skill rather than claiming to use it.
2. Independently examine Python's strongest case and language economics using primary sources. Check: source URLs and bounded agent reports distinguish API facts from unmeasured savings. Expected no language-only claim of lower model prices, tokens or better research quality.
3. Write a story, SWOT and conditional decision with a fair future evaluation design. Check: current Markdown local links, preserved snapshot hashes, whitespace and `git diff --check`. Expected no runtime code or dependency changes and clear proposed versus accepted status.
4. Cross-critique the reasoning and update the living recommendation. Check: bounded independent rereview and repeat documentation validation. Expected concrete objections repaired or retained as explicit prototype questions.
