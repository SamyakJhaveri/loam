## (a) Sandbox
Mechanism: worker runs unsandboxed with `--permission-mode auto` (the lead's posture, J05, J12) instead of bypassPermissions plus sandbox (L bin/factory:2349-2350; worker-settings.json:22-25). Rejected: a sandbox widened with AF_UNIX, local binding and excludedCommands, because bin/check also needs systemd-run's bus, the docker socket, GPU devices, writes under ~/.local/state/distbench (W35 `git worktree add` exit 128) and nested bwrap (W34), and bin/check runs worker-written tests unsandboxed anyway (L LOOP.md:240), so the widened sandbox protects little and keeps breaking on new test kinds.
Lost: (1) the network allowlist (pypi only): Bash can reach GitHub, Slack, rental APIs, any host. (2) the Bash write boundary (worktree plus run roots, LOOP.md:235): Bash can write ~/distbench, ~/distbench-integrate, ~/loam, other runs, ~/.claude. (3) Credentials: already readable today, since the sandbox denies reads only for Read-deny paths (LOOP.md:240); what is lost is the egress barrier for them (~/.codex/auth.json, factory codex-home, ~/.config/gh, ~/.ssh, ~/.distbench alert webhook, account token files, rental keys).
Still guards: per-run worktree and branch (convention, not enforced); deny list, prefix-only (LOOP.md:234), now unioned across factory, project and user tiers; the auto-mode classifier (refuses paid creates and destructive steps, per the lead's record); check_frozen sha256 before each round (L bin/factory:1489-1491) and chmod a-w (:1486); tree_signature around graders (:2716); do-not-touch diff (:2396-2403); the landing gate on the merged tree.
Added structure (cheap, not text): worker env `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=remote.origin.pushurl GIT_CONFIG_VALUE_0=file:///dev/null` and `GH_CONFIG_DIR=<empty run dir>` so `git -C x push` and `/usr/bin/gh` fail even when they evade the prefix deny; deny `Bash(pkill:*)`, `Bash(killall:*)`, `Bash(ssh:*)`, `Bash(scp:*)`; `BASH_MAX_TIMEOUT_MS=5400000` so a gate is not cut at 10 minutes (W35 "timed out after 10m 0s").
Observable: round-N.jsonl init line `permissionMode: auto`; round-N.result.json `.permission_denials`; worker check.log without "AF_UNIX bind denied - sandbox mode".

## (e) Scheduling and gate load
The Stop hook becomes the in-round gate: first the cheap checks with LOAM_HOOK=1; only if they pass, the full checks with bin/check run (lib.sh:24 skip lifted in that phase), timeout raised from 900 s (worker-settings.json:27) to the call timeout. The hook records the result with HEAD and tree_signature in round-N.hook.checks and skips rerunning an unchanged tree. run_checks (L bin/factory:1945-1952) reuses a passing hook record whose signature matches, so a round that passes first time costs one gate, as today; each extra gate replaces a whole later round. bin/check's two slots (isc-build bin/check:122-157) cap concurrent gates at two. factory-isc runs the whole factory run inside distbench-build.slice (today it does not, J16; serial gates escape the slice, J19). MAX_PARALLEL stays the env cap (3 now, 4 after W04, plan line 193). factory-isc refuses a launch while the oldest landing waits longer than two gate runs (plan line 184), mechanically.
Observable: factory.log "checks: reused Stop-hook run at <sha>"; gate slot lines; /proc cgroup of the run.

## (f) Unattended operation
Replace the long-lived lead loop (J01-J03, never handed off) with a systemd user timer every 20 min running D `bin/tick`: flock, a facts script (live runs, heavy count, landing queue age, gate slots, lock holders, owner-events from run folders), then one fresh `claude -p` distbench session (Opus high, auto mode) with the versioned prompt D docs/tickets/TICK.md, which launches through factory-isc and lands through bin/integrate --land. No context to hand off; workers compact at 450K. Dead watch: healthchecks ping per successful tick plus the factory's own holds_slot alerts (L LOOP.md:354-361). Owner-only calls: the tick and the facts script append to ~/.local/state/distbench/NEEDS-SAMYAK.md and send bin/alert needs-you. Observable: ready.log TICK lines, hc ping, NEEDS-SAMYAK.md.
